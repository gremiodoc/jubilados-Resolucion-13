# Consulta de Jubilados – Resolución 13 (Agosto 2026)

Página web estática (HTML + CSS + JS), sin servidor ni base de datos externa.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (ej. `jubilados-resolucion-13`).
2. Sube TODO el contenido de esta carpeta a la raíz del repositorio (incluye `.nojekyll`).
3. Ve a **Settings → Pages → Build and deployment**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En 1–2 minutos tu página estará en `https://TU-USUARIO.github.io/NOMBRE-REPOSITORIO/`.

## Actualizar la lista
Los datos están en `data/jubilados.js` con el formato `"cédula":"D|O|A"` (D=Docente, O=Obrero, A=Administrativo).
