# 🏛️ Consulta Oficial de Jubilados - Resolución 13 Agosto 2026
### Ministerio del Poder Popular para la Educación (MPPE) - República Bolivariana de Venezuela

Página web estática y moderna para consultar el listado oficial de beneficiarios de jubilación según la **Resolución N° 013 (Agosto 2026)**, publicada en Gaceta Oficial N° 472.961 – 472.964.

---

## 🌟 Características Principales

1. **Cintillo Superior Oficial:**
   - Texto institucional: *"Ministerio del Poder Popular para la Educación. República Bolivariana de Venezuela"*.
   - **Logo MPPE** en la esquina superior izquierda.
   - **Logo GD (Gremio Docente)** en la esquina superior derecha.
2. **Cintillo Azul:**
   - Frase destacada: *"Listado de jubilados Resolución 13 Agosto 2026"*.
3. **Buscador Inteligente:**
   - Permite consultar cédulas **con puntos** (`12.345.678`) o **sin puntos** (`12345678`), e incluso con prefijo `V-`.
4. **Respuesta Visual Dinámica:**
   - **Caso Afirmativo:**
     - Mensaje: `"FELICIDADES USTED ESTÁ JUBILADO"`.
     - Indicador de **TIPO de Personal** (`D: Docente`, `O: Obrero`, `A: Administrativo`).
     - **Cambio de color de pantalla según renglón:**
       - 🟦 **Docentes:** Pantalla **Azul**.
       - 🟩 **Administrativos:** Pantalla **Verde Oscuro**.
       - 🟧 **Obreros:** Pantalla **Naranja**.
     - Detalle de Cédula, N° General y Categoría oficial.
     - Botón para imprimir comprobante y botón para realizar otra consulta.
     - Animación de confeti celebratorio sin librerías externas.
   - **Caso Negativo:**
     - Muestra una **Equis roja (X)**.
     - Mensaje exacto: *"Usted no aparece en la lista. La cédula [número] no se encuentra registrada en El Listado Jubilados."*
     - Cuadro secundario inmediato para realizar otra consulta.
5. **Base de Datos Incluida (1.700 Beneficiarios):**
   - 1.592 Docentes
   - 27 Administrativos
   - 81 Obreros
6. **100% Compatible con GitHub Pages:**
   - Cero dependencias externas.
   - Cero requerimientos de backend o servidores.
   - Funciona tanto en línea (GitHub Pages) como abriendo el archivo `index.html` sin conexión a internet.

## 🚀 ¿Cómo publicar esta página en GitHub Pages (Paso a Paso)?

### Opción 1: Crear un nuevo repositorio en GitHub (Recomendado)

1. Ingresa a tu cuenta de [GitHub](https://github.com) y crea un nuevo repositorio público (por ejemplo: `consulta-jubilados` o `jubilados-mppe`).
2. Descomprime el archivo **`consulta-jubilados.zip`**.
3. Sube todos los archivos descomprimidos a la raíz de tu repositorio en GitHub:
   - `index.html`
   - `css/`
   - `js/`
   - `img/`
   - `README.md`
4. En tu repositorio de GitHub, ve a la pestaña **Settings** (Configuración) ➔ en el menú izquierdo haz clic en **Pages**.
5. En la sección **Branch**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`. Haz clic en **Save** (Guardar).
6. ¡Listo! En 1 o 2 minutos tu página estará activa en internet en una dirección como:
   `https://tu-usuario.github.io/consulta-jubilados/`
